# اللغة العربية – الصف الأول الابتدائي – أ/ علاء الشال

ألعاب تعليمية تفاعلية لكتاب **اللغة العربية للصف الأول الابتدائي – الفصل الدراسي الأول**.

- الصفحة الرئيسية: الدخول إلى الوحدات الأربع (مع زر نسخ/مشاركة رابط كل وحدة).
- لكل وحدة رابط مستقل:
  - `unit1/` الوحدة الأولى: أسرتي (أ ب م ح ج د خ ت)
  - `unit2/` الوحدة الثانية: حيواناتي (ل س ن ر ف ك ق)
  - `unit3/` الوحدة الثالثة: أجزاء جسمي (ي ع ش و ه ذ ظ)
  - `unit4/` الوحدة الرابعة: مدرستي (ز ط ص ض ث غ)
- لكل درس (حرف) لعبة واحدة من **20 سؤالًا** متنوعة: اختيار من متعدد – صح أم خطأ – الفقاعات – الأهداف، بلا وقت محدد.
- صوت تشجيع مع الإجابة الصحيحة وصوت محبط مع الخطأ (مع زر كتم الصوت).
- الصور مقتطعة من الكتاب المدرسي نفسه.
- يمكن فتح درس مباشرة بإضافة اسمه بعد # مثل: `unit3/#yaa`
- إرسال النتيجة للمعلم عبر واتساب: 01004030062
